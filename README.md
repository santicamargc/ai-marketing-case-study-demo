# AI Marketing Case Study — GitHub Demo

A deliberately small visual demo used to test the GitHub connector.

## What this tests

- Creating files from ChatGPT
- Writing commits to GitHub
- Working with HTML/CSS stored in a repository
- Reading and modifying the project through the connector
- Preparing a branch + pull request workflow

## Demo

Open `index.html` to view the landing-page source. The page presents an AI-assisted SEO/content case-study snapshot with KPI cards and a four-step workflow.

> The figures shown are case-study figures, not a live analytics connection.
